Sobre nosotros

¿Qué es CinesYPelis?

CinesYPelis es una aplicación web gratuita para descubrir películas: consulta las novedades en cartelera, los próximos estrenos, busca cualquier título y guarda tus favoritos para no olvidarlos.

¿De dónde vienen los datos?

Toda la información de películas (títulos, sinopsis, pósters, valoraciones y disponibilidad en plataformas) proviene de The Movie Database (TMDB), una base de datos colaborativa y gratuita mantenida por la comunidad.

Este producto utiliza la API de TMDB pero no está respaldado ni certificado por TMDB.

¿Dónde ver las películas?

Los datos de disponibilidad en plataformas de streaming son proporcionados por JustWatch. Además, ofrecemos enlaces a Amazon como participantes en el programa de afiliados de Amazon EU, lo que nos permite ganar comisiones por las compras realizadas a través de dichos enlaces.

¿Quién está detrás?

CinesYPelis es un proyecto personal desarrollado por Juan José Fernández. Si tienes alguna sugerencia o consulta, puedes escribirnos a través de la página de contacto.
