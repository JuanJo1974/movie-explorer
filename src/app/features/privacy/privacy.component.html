Política de privacidad

Última actualización: mayo de 2026

1. Datos que recopilamos

CinesYPelis no recopila ni almacena datos personales de sus usuarios. No existe registro de cuentas ni formularios de datos personales. La lista de favoritos se guarda únicamente en el almacenamiento local de tu navegador (localStorage) y nunca se envía a ningún servidor.

2. API de TMDB

Los datos de películas provienen de The Movie Database (TMDB). Las consultas a su API pueden registrar tu dirección IP según la política de privacidad de TMDB.

3. JustWatch

Los datos de disponibilidad en plataformas de streaming son proporcionados por JustWatch a través de TMDB. Al hacer clic en "Ver en JustWatch" serás redirigido a su web, sujeta a su propia política de privacidad.

4. Amazon Associates

CinesYPelis participa en el Programa de Afiliados de Amazon EU, un programa de publicidad para afiliados diseñado para ofrecer a los sitios web un medio para obtener comisiones publicitarias mediante la creación de enlaces a Amazon.es. Al hacer clic en un enlace de Amazon y realizar una compra, podemos recibir una comisión sin coste adicional para ti.

5. Google AdSense y cookies

Esta web utiliza Google AdSense para mostrar anuncios. Google AdSense utiliza cookies para mostrar anuncios relevantes basados en tus visitas a este y otros sitios web. Puedes desactivar el uso de cookies de personalización visitando Configuración de anuncios de Google.

Para más información sobre cómo Google utiliza los datos, consulta la Política de privacidad de Google.

6. Contacto

Para cualquier consulta sobre esta política de privacidad puedes escribirnos a juanjoseft@gmail.com.
